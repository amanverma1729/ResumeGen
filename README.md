# 🚀 ResumeGen - AI Powered Resume Builder

ResumeGen is a modern, ATS-friendly Resume Builder that helps users create professional resumes effortlessly. It provides multiple resume templates, live preview, PDF export, and customizable sections to build job-ready resumes in minutes.

---

## ✨ Features

- 🎨 Multiple ATS-Friendly Resume Templates
- 📄 Live Resume Preview
- 📥 Download Resume as PDF
- 📱 Fully Responsive Design
- ⚡ Fast & Modern User Interface
- 📝 Dynamic Resume Form
- 🎯 Professional Layouts
- 🌙 Clean UI & Easy Navigation
- 🔄 Real-Time Updates
- 💾 Local Storage Support

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/amanverma1729/ResumeGen.git
```

### 2. Navigate to the Project

```bash
cd ResumeGen
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
